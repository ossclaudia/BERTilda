# BERTilda

This repository contains the code accompanying the paper **“BERTilda: Explainable Topic Lifecycle Tracking with Split/Merge Detection via Similarity-and-Flow Temporal Graphs”** by **Cláudia Oliveira** and **Álvaro Figueira**. It implements a framework for tracking topic evolution over time using explainable temporal topic graphs.

## Overview

**BERTilda** (BERT-based Temporal Identification, Lifecycle Detection & Analysis) treats temporal topic modeling as an alignment-and-event-labeling problem on an explicit graph. Topics are discovered independently within each time window using a snapshot topic model (e.g., BERTopic), then linked across adjacent windows using:

1. **Semantic similarity** – measuring similarity between topic embeddings in a shared space.  
2. **Bidirectional document flow** – interpretable signal capturing:
   - Document **outflow** from source topics  
   - Document **inflow** into target topics  

These signals generate a **temporal topic graph**, where transparent rules identify **continuations, splits, merges, disappearances, and ambiguous transitions**.

## Datasets

The following datasets were used in the project:

### Public datasets
- **State of the Union** – [Kaggle link](https://www.kaggle.com/datasets/rtatman/state-of-the-union-corpus-1989-2017)  
- **UN General Debates** – [Kaggle link](https://www.kaggle.com/datasets/unitednations/un-general-debates)  
- **20 Newsgroups** – [Kaggle link](https://www.kaggle.com/datasets/crawford/20-newsgroups)  

### Project folders

#### `.pkl`
Contains **embeddings** and topic information generated by BERTopic for:

- 119th Congress Tweets dataset  
- UN Debates dataset  
- State of the Union dataset  

#### `119congresstweets`
Includes data related to the 119th US Congress:

- `Twitters_119thCongressMembers.xlsx` – member metadata (Name, Role, State, District, Party, Served, Active On X, Account)  
- `tweets.csv` – member metadata and raw tweet data (favorite_count, retweet_count, reply_count, view_count, created_at, hashtags, urls, media_type, media_urls)  
- `cleanedtweets.csv` – preprocessed tweets used for modeling  
- Model metrics – files named `...results.csv`  
- Topic detection outputs – `bertilda.csv`  
- Topic relations – `bertilda_mergeandsplits.csv`  

#### `GoldSet`
Contains:

- Variations of BERTilda outputs  
- Annotator answers (from three annotators)  

#### `stateofunion` & `undebates`
Contains:

- Preprocessed tokens (`*_tokens`)  
- Results from all models applied to these datasets
